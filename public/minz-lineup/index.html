개발 중 · 런타임 미제공

MINZ AI Control Plane

AI 작업의 정책·capability·승인 경계를 정리하는 제어 계층을 개발하고 있습니다.

공개하는 자료

Windows foundation 확인과 별개로 R13 source/runtime provenance는 아직 검증되지 않았습니다. 현재는 비실행 상태 예제만 제공합니다.

Worker 실행, queue 소비, shared scheduler 및 자동 라우팅은 활성화하지 않았습니다. R13이 실행 가능한 제품인 것처럼 안내하지 않습니다.

공개 파일 사용법

  1. 제품에 맞는 참조팩 또는 JSON 예제를 내려받습니다.
  2. 공개 manifest의 파일명·크기·SHA-256과 다운로드한 파일을 비교합니다.
  3. 참조팩은 읽기 전용 자료로 살펴보세요. JSON 샘플은 실행 명령이나 설치 파일이 아닙니다.

해시 일치는 파일 내용 확인입니다. 작성자 인증, 시스템 실행 허가나 성과 인증을 대신하지 않습니다. 원본 팩의 라이선스 공지를 함께 확인하세요.
