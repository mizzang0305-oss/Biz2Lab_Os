# 신뢰 페이지 설계안

상태: `SUPERSEDED_BY_EXACT_DRAFT_SURFACES_NOT_IMPLEMENTED`

정확한 공개 문구 초안은 `trust-surfaces/`의 7개 문서에 있다. 이 파일은 초기 정보구조 blueprint로 보존하며 구현·공개 source of truth가 아니다.

## `/ko/about`

- 사이트의 건강 교육 목적과 대상 독자
- 실제 운영 주체
- 의료기관이 아니며 개인 상담을 제공하지 않는다는 경계
- 콘텐츠 제작·검토 방식으로 연결

## `/ko/editorial-policy`

- 한국 공공기관 우선의 출처 계층
- 일반 독자 언어로 독립 작성하는 원칙
- 생성형 AI를 조사·초안 보조에 쓸 수 있으나 사실 검증과 발행 결정은 사람이 맡는다는 원칙
- 광고·제휴와 편집 판단의 분리
- 이해상충 공개

## `/ko/medical-review`

- `SOURCE_CHECKED`와 `CLINICIAN_REVIEWED`의 정의
- 실제 의료 검수자가 없는 글의 명확한 표시
- 검토일, 검토 범위, 재검토 조건
- 응급·진단·치료 정보의 강화된 검토 절차

## `/ko/sources-policy`

- 질병관리청·보건복지부·국가 공공기관 우선
- WHO·NIH/NLM·NHS 등 국제 자료의 보조 역할
- 상업 사이트와 커뮤니티의 제한
- 출처 충돌 시 발행 중단 및 해소 방식
- 확인일과 원문 링크 표시

## `/ko/corrections`

- 오류 제보 방법
- 접수, 영향 평가, 수정, 의료 재검토, 공개 이력의 흐름
- 응급 행동·약물·진단 오류의 최우선 처리
- 단순 오탈자와 의료 의미 변경의 이력 구분

## `/ko/contact`

- 실제 수신 가능한 오류 제보 경로
- 개인 의료상담을 받지 않는다는 안내
- 응급·정신건강 위기에는 공식 도움 경로 안내
- 민감한 건강 정보를 보내지 말라는 경고

## `/ko/privacy`

- 실제 사용하는 분석·광고·로그 도구와 쿠키
- 수집 목적, 보관, 제3자 제공, 권리 행사 방법
- 증상·진단·약물 같은 건강 정보 입력 기능을 기본적으로 제공하지 않음
- 향후 건강 정보 기능은 별도 개인정보·법률 검토 전 추가하지 않음

## `/ko/disclaimer`

- 일반 교육 목적
- 개인 진단·처방·응급실·약사 상담 대체 아님
- 응급 상황에서는 119 또는 가까운 응급실 이용
- 링크된 외부 자료의 업데이트 시차 가능성

## 공개 게이트

페이지 카피는 실제 운영 정보와 코드에서 사용하는 데이터 처리 도구를 확인한 뒤 작성한다. 기존 Biz2Lab 정책 페이지를 단순 명칭 변경하지 않고, 새 건강 사이트의 실제 운영과 일치하는지 법률·개인정보 관점에서 Owner가 검토한다.
