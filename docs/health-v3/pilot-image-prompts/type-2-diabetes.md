# Pilot image prompts — 제2형 당뇨병

상태: `PROMPT_ONLY_SOURCE_AND_LICENSED_REVIEW_REQUIRED`

공통: 따뜻하고 비낙인적인 원본 벡터 교육 일러스트. 다양한 체형과 연령을 존중한다. 음식 하나·체형·의지 부족을 단일 원인으로 표현하지 않는다. 숫자 기준·제품·약물 용량·긴 이미지 텍스트 없음. 생성 provenance와 AI 생성 여부를 기록한다.

## Hero — VIS-DIA-01

목적: 혈당 기록이 약 조절이 아니라 진료 질문 준비임을 설명. 기록표와 질문표를 준비하는 성인. 주사·약을 행동 결론으로 강조하지 않고 측정값 판정 색상을 쓰지 않는다.

## Body-process — VIS-DIA-02

목적: 음식에서 얻은 포도당→혈액→인슐린 신호→세포 이용의 단순 관계. 비유는 개념 이해만 돕고 인슐린을 실제 열쇠나 모든 당뇨병의 단일 기전처럼 표현하지 않는다.

## Urgent warning — VIS-DIA-03

목적: 의식 변화·심한 탈수·저혈당 의심 혼란에서는 기록보다 도움 요청이 우선임을 표시. 증상만으로 고혈당·저혈당을 확진하거나 특정 음식을 일률적으로 처방하지 않는다.

## Action checklist — VIS-DIA-04

목적: 가족이 음식·체형을 비난하거나 약을 통제하지 않고 기록과 진료 질문을 함께 준비하는 장면. 당사자 동의와 존중이 중심인 세로 체크 카드.
