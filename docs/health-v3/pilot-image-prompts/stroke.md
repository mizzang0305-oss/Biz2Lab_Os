# Pilot image prompts — 뇌졸중

상태: `PROMPT_ONLY_LICENSED_REVIEW_REQUIRED`

공통: 비공포·비고어 원본 벡터 응급 교육 일러스트. 실제 CT·MRI·병원 로고·환자 사진을 모사하지 않는다. 온라인 퀴즈나 단계가 119를 지연시키지 않게 모든 구성에서 도움 요청을 우선한다. claim map과 면허 검토 전 생성·공개하지 않는다.

## Hero — VIS-STR-01

목적: 얼굴·팔·말의 갑작스러운 변화 뒤 119 행동을 기억. 휴대전화 도움 요청과 시작 시각 기록이 중심인 16:9 구성. 모든 증상을 확인해야 한다는 흐름 금지.

## Body-process — VIS-STR-02

목적: 막힘과 출혈 두 가능성을 단순 비교하되 독자가 구분할 수 없고 병원 평가가 필요함을 공통 화살표로 표현. 손상된 뇌를 공포스럽게 묘사하지 않는다.

## Urgent warning — VIS-STR-03

목적: 얼굴·팔·말·시간을 네 카드로 표시. 시간 카드는 증상 소실을 기다리는 시계가 아니라 시작 시각 기록과 즉시 119를 의미한다.

## Action checklist — VIS-STR-04

목적: 119→시작 시각→알고 있는 약·병력 준비 순서를 큰 번호로 표현. 정보표 작성·음식·물·약 제공이 신고보다 앞서지 않는다.
