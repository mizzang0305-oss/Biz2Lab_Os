# Pilot image prompts — 심근경색

상태: `PROMPT_ONLY_LICENSED_REVIEW_REQUIRED`

공통: 차분하지만 긴급 행동이 명확한 원본 벡터 교육 일러스트. 공포스러운 통증 표정·수술·피·실제 심전도·브랜드 제품 없음. 도움 요청을 자가 판별보다 우선하고 증상 다양성을 존중한다.

## Hero — VIS-MI-01

목적: 심한 가슴 불편감과 관련 신호가 있을 때 소화불량인지 시험하지 않고 119를 요청. 직접 운전 장면·소화제 반응 비교·확진 표시 금지.

## Body-process — VIS-MI-02

목적: 관상동맥이 심장 근육에 피를 공급하고 막히면 공급이 줄 수 있다는 세 단계 흐름. 혈관 위치·방향은 사람 의료 검토가 필요하며 치료 결과를 보장하지 않는다.

## Urgent warning — VIS-MI-03

목적: 가슴 압박·퍼지는 불편감·호흡곤란·식은땀과 메스꺼움을 네 카드로 보여 주고 119 행동을 함께 표시. 증상 하나로 확진하거나 모든 사람에게 같은 증상이 있다고 단정하지 않는다.

## Action checklist — VIS-MI-04

목적: 응급 정보 준비와 퇴원 후 처방·재활 질문을 명확한 두 구역으로 분리. 회복 단계의 활동·약물 조정을 그림이 지시하지 않는다.
