# Benchmark Analysis

## 결론

Biz2Lab은 어느 한 사이트의 축소판이 되어서는 안 된다. 국내 기준은 국가건강정보포털에서, 행동 단계는 NHS에서, 쉬운 읽기와 연결 구조는 MedlinePlus에서, 어린이 눈높이는 KidsHealth에서 배운다. 설명과 그림은 새로 제작하고 문장을 복사하지 않는다.

## 공통적으로 강한 패턴

1. 독자가 처음 보는 화면에서 “무엇인지”와 “지금 무엇을 해야 하는지”를 구분한다.
2. 질환 설명과 응급 행동을 같은 문단에 묻지 않고 별도 시각 box로 만든다.
3. 증상만 나열하지 않고 검사, 치료 목적, 생활관리, 가족 역할로 이어진다.
4. 출처와 update/review 정보를 페이지 단위로 보여준다.
5. 어려운 용어를 쉬운 말·그림·용어사전으로 여러 번 접근할 수 있게 한다.
6. 연령과 역할에 따라 환자, 가족, 어린이의 질문이 다름을 인정한다.

## Biz2Lab의 차별화 가능한 편집 가치

- 한국의 119·응급실·건강검진 문맥으로 행동을 구체화한다.
- “오늘 할 수 있는 3가지”와 “가족이 같이 확인할 것”을 분리한다.
- 같은 증상이 다른 질환에서도 나타날 수 있음을 명시해 자가진단을 억제한다.
- 한 장의 original visual마다 하나의 학습 목표만 둔다.
- 기사마다 `무엇을 모르는지`와 `어떤 경우 의료진 판단이 필요한지`를 공개한다.

## 복제하면 안 되는 것

- 공식 사이트 문장의 순서·표현을 그대로 바꾸어 쓰기
- 기관 이미지를 다운로드해 색만 바꾸기
- 국내 기준이 필요한 곳에 해외 수치·응급번호 사용
- “전문의가 쓴 것처럼” 보이는 말투와 author schema
- 모든 질환에 동일한 15개 heading을 기계적으로 반복

## AdSense·Search 해석

Google의 공식 문서는 건강 주제를 승인 우대 분야라고 말하지 않는다. 오히려 건강·안전에 영향을 주는 YMYL 콘텐츠에는 강한 신뢰 신호가 더 중요하다고 안내한다. 이번 benchmark의 목적은 승인 공식 추정이 아니라 독자가 실제로 이해하고 안전하게 행동하도록 만드는 것이다.
