# 사람 저자·신뢰 정보 입력 필요

상태: `SUPERSEDED_BY_P01_FOUR_OWNER_INPUTS`
주의: 아래 값이 확인되기 전에는 추정값이나 가상 인물을 공개하지 않는다.

이 문서는 초기 질문 목록으로 보존한다. 현재 유효한 Owner 입력 계약은 `batch0-owner-input-required.md`와 `p01-health-v3-owner-trust-completion.md`의 A–D 네 묶음이다. 아래 항목 중 제작·검토 과정에서 생기는 값은 execution evidence이며 추가 Owner 정책 질문으로 계산하지 않는다.

## 1. Owner가 제공해야 할 사실

| 항목 | 필요한 입력 | 공개 전 증빙/확인 |
|---|---|---|
| 사이트 운영 주체 | 개인 또는 법인의 실제 표시명 | Owner 확인 |
| 책임 편집자 | 실제 이름 또는 일관된 공개 필명 | 본인 동의 및 소개문 |
| 저자 경력 | 건강 교육 글과 관련된 사실 기반 경력 | 과장 없는 원문 확인 |
| 의료 자격 | 보유한 경우에만 자격명·발급 주체 | 자격 증빙과 공개 동의 |
| 의료 검수자 | 실제 검수 참여자 이름·전문 분야 | 참여 동의와 자격 확인 |
| 연락 경로 | 독자가 오류·정정을 제보할 실제 채널 | 수신·응답 가능 여부 |
| 편집 독립성 | 광고·제휴·후원의 편집 영향 정책 | 실제 사업 모델과 일치 |
| 정정 책임자 | 오류 접수·검토·수정 담당자 | 운영 가능 여부 |

의료 전문가가 참여하지 않는다면 `의료 전문가 검수`라고 쓰지 않는다. 대신 `공공기관 자료를 바탕으로 편집한 일반 건강 정보이며 의료 전문가의 개별 진료를 대체하지 않는다`고 정확히 공개한다.

## 2. 신뢰 페이지 최소 세트

- `/ko/about`: 운영 목적, 대상 독자, 운영 주체
- `/ko/authors`: 실제 저자별 소개와 작성 범위
- `/ko/medical-review`: 검수 기준, 참여자, 검수하지 않은 글의 표시 방식
- `/ko/editorial-policy`: 출처 우선순위, AI 사용 경계, 정정 절차
- `/ko/contact`: 실제 작동하는 문의·오류 제보 경로
- `/ko/advertising`: 광고와 편집의 분리, 제휴 공개
- `/ko/disclaimer`: 일반 교육 목적과 응급 상황 안내
- `/ko/privacy`: 수집 데이터와 실제 분석·광고 도구의 일치

## 3. 공개 전 질문

1. 운영 주체의 실제 공개명은 무엇인가?
2. 책임 편집자의 이름 또는 공개 필명과 사실 기반 소개문은 무엇인가?
3. 의료 전문가가 실제로 모든 핵심 글을 검수할 수 있는가? 가능하다면 누구이며 어떤 범위를 맡는가?
4. 오류 제보를 받을 이메일 또는 폼은 무엇이며 누가 응답하는가?
5. 건강 정보 입력·상담·뉴스레터 기능을 운영할 계획이 있는가? 있다면 별도 개인정보·법률 검토가 필요하다.
6. 광고·제휴·상품 판매 계획이 있는가? 있다면 편집 분리 정책에 반영해야 한다.

## 4. 미해결 상태의 처리

- 확인되지 않은 저자·법인·주소·자격·수상·경력을 만들지 않는다.
- 의료 검수자가 없으면 검수자 구조화 데이터도 만들지 않는다.
- 연락 경로가 검증되지 않으면 `ContactPoint`를 공개하지 않는다.
- 법률 검토가 없는 상태에서 개인정보·의료상담 기능을 추가하지 않는다.
- 위 입력이 완료되기 전 첫 의료 기사 발행은 사람 승인 게이트에서 중단한다.
