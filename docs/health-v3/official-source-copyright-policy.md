# 공식 출처 저작권·표현 사용 정책

상태: `INTERNAL_EDITORIAL_GUARD`

기준 확인일: 2026-08-22 KST

이 문서는 Biz2Lab Health V3의 보수적 내부 제작 규칙이다. 법률 자문이나 각 저작물의 개별 이용허락을 대신하지 않는다.

## 1. 사실 확인과 표현물 사용을 분리한다

- 공식 의료 사실은 조사하고 claim 단위로 출처를 연결할 수 있다.
- 사실을 확인했다는 이유만으로 출처의 표현·구성·시각물을 복제할 권리가 생기는 것은 아니다.
- 원문의 문단, 표, 도식, 삽화 또는 화면을 복사하지 않는다.
- 단일 출처의 문장 구조와 전개를 따라가는 근접 의역을 하지 않는다.
- 가능한 경우 둘 이상의 공식 출처를 비교하고, 확인된 개념을 바탕으로 독립적인 설명을 새로 쓴다.
- 각 의료 claim에는 실제 확인한 source URL과 확인 기록을 유지한다.
- 짧은 직접 인용이 필요하더라도 이용조건과 인용 요건을 별도로 확인하고 최소 범위로 제한한다.

## 2. 이미지·도식·생성형 도구 규칙

- 공식 출처의 이미지·도식·삽화를 다운로드해 재게시하지 않는다.
- 상업적 2차적 이용이 명시적으로 허용되지 않은 공식 이미지를 image-generation reference 또는 image transformation 입력으로 사용하지 않는다.
- “공공기관 자료”라는 이유만으로 상업적 재사용·변형이 자유롭다고 가정하지 않는다.
- 시각물은 독립적으로 검증한 개념, 자체 visual claim map, 자체 프롬프트를 바탕으로 원본 제작한다.
- 원본 제작물도 의료 의미, privacy, 유사성, 출처 기록을 사람 검토한다.

## 3. KDCA 국가건강정보포털 전용 규칙

질병관리청 국가건강정보포털의 저작권 안내는 질병관리청이 저작재산권을 보유하고 공공누리 표시가 부착된 자료를 공공누리 제4유형으로 안내한다. 공공누리 제4유형의 핵심 조건은 다음 세 가지다.

- 출처표시
- 상업적 이용 금지
- 변경 또는 2차적 저작물 작성 금지

Biz2Lab Health V3는 향후 광고가 포함될 수 있으므로 다음의 더 엄격한 내부 경계를 적용한다.

- KDCA 제4유형 문장·표·이미지·영상은 재게시하지 않는다.
- 해당 이미지·도식·영상은 수정하지 않는다.
- 해당 시각물을 이미지 변환·생성 reference로 입력하지 않는다.
- KDCA 자료는 의료 사실 확인과 독자가 직접 확인할 outbound source link에만 사용한다.
- 설명과 삽화는 여러 공식 출처에서 독립적으로 검증한 개념을 바탕으로 새로 만든다.
- 특정 자료에 별도 라이선스가 표시되면 그 개별 조건을 다시 확인하며, 불명확하면 사용하지 않는다.

## 4. 제작·검수 기록

각 공개 후보는 다음을 남겨야 한다.

1. claim별 공식 source URL과 확인일
2. 원문과 다른 독립적 설명이라는 편집자 확인
3. 표·도식·이미지의 자체 제작 근거와 입력 출처 설명
4. 외부 표현물 복제·근접 의역·금지된 변형이 없다는 사람 검토
5. 이용조건이 불명확한 자산의 제외 기록

자동 문자열 검사는 긴 동일 문구 탐지에 도움을 줄 뿐 저작권 안전을 증명하지 않는다. 최종 공개 전 사람의 원문 대조가 필요하다.

## 5. 공식 근거

- 질병관리청 국가건강정보포털, 건강정보 활용방법/저작권: https://health.kdca.go.kr/healthinfo/biz/health/portalUseGuidance/hlthinsReqst/hlthinsReqstMth.do
- 공공누리 공식 이용조건 안내: https://www.kogl.or.kr/recommend/learningDataList.do

## 6. 차단 조건

다음 중 하나라도 있으면 `BLOCKED_COPYRIGHT_RISK_DETECTED` 후보로 분류하고 공개하지 않는다.

- 출처 문단·표·그림·삽화의 복제
- 한 출처를 따라 쓴 근접 의역
- 이용조건을 확인하지 않은 이미지 reference 사용
- KDCA 제4유형 자료의 광고 가능 사이트 재게시 또는 변형
- 자체 제작·출처·검토 기록 부재
