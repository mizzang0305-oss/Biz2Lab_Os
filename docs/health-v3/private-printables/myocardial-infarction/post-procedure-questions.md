# 심근경색 치료·시술 후 질문표

상태: `PRIVATE_PROTOTYPE_LICENSED_REVIEW_REQUIRED`

Claim map: `MI-010`, `MI-011`

- 어떤 문제가 확인됐고 어떤 치료 또는 시술을 받았나요?
- 처방약 각각의 목적과 중요한 주의점은 무엇인가요?
- 약을 잊었거나 이상 증상이 있을 때 어디에 연락하나요?
- 어떤 증상이 생기면 즉시 119를 요청해야 하나요?
- 활동·운전·업무 복귀는 누구와 언제 상의하나요?
- 심장 재활이 제게 적절한가요?
- 상처나 시술 부위에서 어떤 변화를 관찰하나요?
- 다음 진료와 검사는 언제인가요?

개인의 퇴원 안내가 우선이다. 이 표는 약물 용량·활동 수준을 결정하지 않는다.
