# 혈압 기록 중 나타나면 기록보다 도움 요청이 우선인 신호

상태: `PRIVATE_PROTOTYPE_LICENSED_REVIEW_REQUIRED`

Claim map: `HTN-007`, `HTN-008`

다음과 같은 갑작스럽고 심한 증상이 있으면 혈압을 반복해 재느라 기다리지 말고 119 또는 가까운 응급실에 도움을 요청한다.

- 얼굴·한쪽 팔·다리의 갑작스러운 힘 빠짐 또는 마비
- 말이 어눌해지거나 이해하기 어려움
- 심한 가슴 통증 또는 압박감
- 심한 호흡 곤란, 실신, 의식 저하

이 카드는 혈압 수치만으로 응급 여부를 판정하지 않는다. Source gate: KR-003, KR-017, KR-018. 공개 전 면허 의료 검토가 필요하다.
