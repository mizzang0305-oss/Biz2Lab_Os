# 혈압 측정 전 체크리스트

상태: `PRIVATE_PROTOTYPE_NOT_FOR_PUBLICATION`

Claim map: `HTN-003`, `HTN-006`, `HTN-011`

교육용 준비표이며 측정 한 번으로 고혈압을 진단하지 않는다.

- [ ] 측정 전에 잠시 편안히 앉았다.
- [ ] 등은 기대고 발은 바닥에 두었다.
- [ ] 다리를 꼬지 않았다.
- [ ] 팔을 편안히 받쳤다.
- [ ] 상완에 맞는 커프를 사용했다.
- [ ] 같은 조건의 날짜와 시각을 기록했다.
- [ ] 숫자가 걱정돼도 처방약을 임의로 바꾸지 않았다.
- [ ] 기기·커프·측정 횟수는 의료진에게 확인할 질문으로 남겼다.

Source gate: KR-003. 실제 공개 전 세부 측정 절차를 원문과 다시 대조한다.
