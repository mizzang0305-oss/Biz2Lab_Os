# Health V3 일러스트레이션 시스템

상태: `DESIGN_SPEC_ONLY`
현재 생성된 공개 이미지: 없음

## 1. 목적

시각 자료는 질환을 쉽게 이해시키기 위한 교육 자산이다. 공포, 충격, 클릭 유도 또는 전문 의료행위의 모방을 목적으로 하지 않는다.

## 2. 공통 스타일

- 깔끔한 한국어 건강 교육 인포그래픽 스타일
- 밝은 중성 배경, 차분한 청록·파랑 계열을 기본으로 사용
- 위험 신호는 제한적으로 주황·빨강을 사용하되 공포스럽게 만들지 않음
- 다양한 연령과 성별의 일반적인 인물을 존중하는 방식으로 표현
- 피, 수술 장면, 신체 훼손, 과장된 통증 표정은 사용하지 않음
- 실제 환자 사진처럼 보이는 이미지를 만들지 않음
- 공공기관 도판·병원 이미지·경쟁 사이트 레이아웃을 복제하지 않음
- 이미지 안의 긴 문장은 생성하지 않고, 텍스트·레이블은 접근 가능한 HTML 또는 검수 가능한 SVG 오버레이로 제공

## 3. 질환별 4종 자산

1. `hero`: 질환과 관련 신체 부위를 친절하게 소개하는 대표 이미지
2. `explainer`: 원인 또는 신체 변화의 단순화된 흐름도
3. `warning-signs`: 즉시 진료·응급 도움을 고려할 신호 카드
4. `management`: 예방·일상 관리 행동을 보여 주는 체크리스트형 이미지

각 자산은 본문을 대체하지 않는다. 이미지에 담긴 모든 의료 의미는 본문과 대체 텍스트에도 있어야 한다.

## 4. 기술 계약

- 권장 원본 비율: hero 16:9, 나머지 4:3 또는 세로형 카드
- 파생 포맷: AVIF/WebP 우선, 필요 시 PNG
- 장식용 이미지는 빈 `alt`; 교육 정보를 가진 이미지는 핵심 의미를 설명하는 한국어 `alt`
- 파일명: `{disease-slug}-{asset-type}-v1.{ext}`
- provenance: 생성 도구, 프롬프트 버전, 생성일, 사람 검토자, 출처 참고 여부를 기록
- 실제 발행 전 모바일 가독성, 색상 대비, 잘림, 의학적 방향·위치 오류를 사람 눈으로 확인

## 5. 금지 표현

- “정상/비정상 사람”을 외모로 구분
- 체형·장애·정신건강 상태를 조롱하거나 낙인화
- 한 이미지가 치료 효과 전후를 보장하는 구성
- 주사·약을 특정 제품처럼 홍보
- 응급 행동을 잘못 보여 주는 장면
- 로고, 워터마크, 공공기관 고유 도형을 무단 모사

## 6. 이미지 승인 체크

- [ ] 질환의 신체 위치와 방향이 의학적으로 타당하다.
- [ ] 위험 신호가 본문·공식 출처와 일치한다.
- [ ] 자가 진단이나 치료 보장으로 읽히지 않는다.
- [ ] 실제 인물·환자·저작물의 복제가 아니다.
- [ ] `alt`가 이미지 목적을 전달한다.
- [ ] 작은 화면에서도 정보 순서가 유지된다.
- [ ] 이미지 속 텍스트가 있다면 별도 교정했다.
- [ ] 사람 편집자와 의료 정확성 검토를 통과했다.
