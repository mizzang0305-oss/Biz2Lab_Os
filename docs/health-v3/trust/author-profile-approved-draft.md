# 박영훈 | 비의료인 건강정보 편집자

공공기관과 의료기관의 환자용 자료를 일반인이 이해하기 쉬운 말과 그림, 기록표와 질문 도구로 다시 정리합니다.

역할은 `NON_CLINICIAN_HEALTH_INFORMATION_EDITOR`다. 의사, 간호사, 약사, 치료사, 영양사 또는 임상 연구자 자격을 주장하지 않는다.

- 진단을 제공하지 않는다.
- 처방이나 약물 변경 지시를 제공하지 않는다.
- 개인 치료 결정을 대신하지 않는다.
- 공식 출처를 확인하는 절차와 면허 의료인의 검수는 서로 다르다.

작성자 표시는 출처 확인, 의료인 검수 또는 공개 준비 완료를 의미하지 않는다. 각 상태는 페이지별로 따로 표시한다.
