# 비의료 독자 3인 이해도 테스트

상태: `HUMAN_READER_TEST_PENDING`

Codex는 질문지와 기록 양식만 만든다. 응답과 점수는 실제 참가자가 제공해야 하며 만들거나 추정하지 않는다.

## 참가자

- 의료 직종이 아닌 한국어 독자 3명
- 가능하면 연령·건강정보 이해 경험이 서로 다른 사람
- 개인 질환·진단·의료기록을 요구하지 않음
- 테스트 목적과 기록 범위에 동의한 사람

## 진행 방식

1. 세 명의 실제 비의료 독자에게 네 파일럿 각각과 연결된 도구를 제공한다. 같은 세 명이 네 페이지를 모두 평가할 수 있다.
2. 설명 없이 읽게 하고 완료 시간을 선택적으로 기록한다.
3. 다음 질문을 그대로 묻되 개인 진단을 요청하지 않는다.
4. 답변은 참가자의 표현을 그대로 기록한다.
5. 잘못 이해한 응급 행동이 있으면 테스트 후 즉시 공식 행동을 정정한다.
6. 결과를 의료 효과나 대표 사용자 통계로 일반화하지 않는다.

## 필수 질문

1. 이 페이지는 어떤 질환을 설명했나요?
2. 이 상황에서 가장 먼저 해야 할 일은 무엇이라고 이해했나요?
3. 어떤 신호가 긴급한 도움을 필요로 하나요?
4. 가장 이해하기 어려웠던 부분은 무엇인가요?
5. 반복된다고 느낀 부분은 무엇인가요?
6. 믿기 어렵거나 신뢰가 가지 않은 부분은 무엇인가요?
7. 저장하거나 출력하고 싶은 것은 무엇인가요?
8. 가족에게 보여주고 싶은 부분은 무엇인가요?
9. 진단이나 처방처럼 들린 문장이 있었나요?
10. 기계가 만든 글처럼 느껴졌나요? 그렇게 느낀 부분은 무엇인가요?

## 관찰 항목

- 응급 페이지에서 119보다 다른 행동을 먼저 말하는지
- 기록 도구를 자가 진단·약물 변경에 쓰려는지
- 실제 저자·검수 상태를 정확히 이해하는지
- composite/general example을 실제 환자 사례로 오해하는지
- 이미지 없이도 행동 순서를 이해하는지

## 완료 기준

- 참가자 3명의 원문 응답이 존재
- 네 파일럿 각각에 대해 세 참가자의 응답이 존재
- 개인 의료정보가 기록되지 않음
- 위험한 오해는 claim·문구·시각물에 수정으로 연결
- 수정 후 필요한 항목은 재시험
- 결과는 `3명 테스트`로만 표시하고 전체 사용자 대표 수치로 확대하지 않음
