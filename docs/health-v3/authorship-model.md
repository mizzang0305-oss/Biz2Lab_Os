## 역할 분리

| 역할 | 수행 가능 업무 | 수행할 수 없는 주장 | 필수 기록 |
|---|---|---|---|
| Author | 독자 과제 정의, 쉬운 문장 작성, 도구 설계 | 의료 면허·진료 경험·임상 판단 | 실제 이름/필명, 사실 기반 소개, 작성일 |
| Source checker | 공식 원문과 문장 대조, 출처 날짜 기록 | 사람 의료 검수로 표시 | 확인자, 확인 범위, 확인일, 원문 URL |
| Licensed medical reviewer | 면허가 검증된 경우 임상 정확성·응급·치료 경계 검토 | 검토하지 않은 전체 사이트 보증 | 실제 신원, 면허 종류, 검토 범위·날짜·결과 |
| Illustrator | 승인된 claim map으로 교육 시각물 제작 | 진단 영상·의학 검수자 역할 | 제작자/도구, prompt, 생성일, asset hash |
| Site operator | 사이트·연락·개인정보·광고 운영 | 저자나 검수자 역할 자동 승계 | 운영 주체, 정책 책임자, 연락 경로 |

한 사람이 여러 역할을 맡을 수 있지만 각 역할의 실제 수행과 자격을 별도로 기록한다. 사이트 운영자라는 이유만으로 의료 검수자가 되지 않으며, 출처를 확인했다는 이유만으로 면허 검수를 완료한 것이 아니다.

## 공개 표시 규칙

- 확인되지 않은 placeholder를 공개하지 않는다.
- `Source checked`는 확인자와 확인일이 있을 때만 쓴다.
- `Clinician reviewed`는 실제 면허 검증, 문서별 검토 기록, 공개 동의가 모두 있을 때만 쓴다.
- 의료 검수자가 없으면 그 사실을 숨기거나 generic badge로 대체하지 않는다.
- AI는 저자·source checker·의료 검수자로 표시하지 않는다.

## 금지되는 역할 혼동

- 비의료 편집자를 의사처럼 보이게 하는 흰 가운·청진기 프로필
- `전문가가 작성`처럼 전문가가 누구인지 알 수 없는 표현
- 한 질환 검수를 전체 사이트 의료 보증으로 확대
- 공공기관 자료 사용을 공공기관의 승인·제휴로 표현
- 그림 생성자를 해부학 또는 임상 검수자로 표시
