## Batch 0.7 Current Screening Status

이 문서는 Batch 0.6 시점의 다섯 후보 스냅샷을 보존한다. 현재 검토 대상은 `곁살핌` 1개이며, backup은 `살핌길`이다. 이는 상표·도메인·공개 사용 승인이나 법적 clearance가 아니다.

- `살핌노트`: Owner의 외부 관찰상 active health-information usage 우려로 primary shortlist에서 제외
- `몸안내`: 일반명사성이 높아 primary shortlist에서 제외
- `곁건강`: 일반적 건강·공공서비스 표현과의 혼동 우려로 primary shortlist에서 제외
- `곁살핌`: `GYEOTSALPIM_HUMAN_KIPRIS_CHECK_READY`
- `살핌길`: `BACKUP_ONLY_NOT_CLEARED`

아래 다섯 후보는 언어·역할 경계와 제한된 공개 조사에서 남긴 후보일 뿐이다. 모두 `TRADEMARK_HUMAN_VERIFICATION_REQUIRED`이며 법적·상표상 clearance가 아니다.

## 1. 곁살핌 — Primary Recommendation

- 발음/로마자: 곁-살핌 / `gyeotsalpim`
- 의미: 독자와 가족 곁에서 건강 정보를 차분히 함께 살핀다는 뜻
- tagline 후보: “몸의 신호를 이해하고 필요한 도움을 찾는 안내”
- brand story: 병원을 대신하지 않고, 독자가 자료를 이해하고 질문·기록을 준비하도록 돕는 비의료 편집 브랜드
- 강점: 따뜻함, 가족 유용성, 비의료 정체성, 편집 확장성의 균형
- 약점: 건강 정체성이 이름만으로 즉시 드러나지 않으며 돌봄기관으로 오인될 수 있음
- preliminary trademark state: `TRADEMARK_HUMAN_VERIFICATION_REQUIRED`
- domain state: `gyeotsalpim.com`은 RDAP 404·DNS 미해결 관찰만 있음; `DOMAIN_APPEARS_AVAILABLE_UNCONFIRMED`
- search-confusion state: `SEARCH_RESEARCH_INCOMPLETE`
- trust risk: 의료 권위 낮음, 돌봄 제공자 오인 가능성 중간
- domain architecture fit: D1 또는 D2 모두 가능하나 별도 Owner 결정 필요
- 다음 사람 확인: KIPRIS 음성·관념 유사 및 5명 read-aloud test

## 2. 살핌노트 — Safest Conservative Option

- 발음/로마자: 살핌-노트 / `salpimnote`
- 의미: 이해한 정보를 정리하고 질문을 준비하는 노트
- tagline 후보: “알아두고 기록하고 질문하는 건강 안내”
- brand story: 건강 정보를 지식 과시가 아닌 이해·기록·대화 준비 도구로 다루는 편집 브랜드
- 강점: 기능 경계가 분명하고 의료기관·정부 오인이 낮음
- 약점: 문구·기록앱으로 좁혀 보일 수 있어 기사·시각 교육까지의 확장성을 설명해야 함
- preliminary trademark state: `TRADEMARK_HUMAN_VERIFICATION_REQUIRED`
- domain state: `salpimnote.com`은 RDAP 404·DNS 미해결·public archive no-capture 관찰만 있음; `DOMAIN_APPEARS_AVAILABLE_UNCONFIRMED`
- search-confusion state: `SEARCH_RESEARCH_INCOMPLETE`
- trust risk: 의료 권위 낮음, 개인 건강기록 수집 서비스 오인 가능성 낮음~중간
- domain architecture fit: D1, D2, D3 모두 가능하나 D2에서는 새 도메인 신뢰 구축 비용이 큼
- 다음 사람 확인: KIPRIS의 노트·출판·디지털 정보 유사표장 및 기록 수집 오인 reader test

## 3. 몸안내 — Most Memorable Option

- 발음/로마자: 몸-안내 / `momannae`
- 의미: 몸과 건강에 관한 쉬운 안내
- tagline 후보: “쉬운 말로 이해하는 건강 정보”
- brand story: 복잡한 건강 정보를 의료 조언 없이 읽기 쉬운 안내로 바꾼다는 약속
- 강점: 처음 듣는 독자도 건강교육 목적을 바로 이해하기 쉬움
- 약점: 일반명사 성격이 강하고 공공기관 안내문·건강서비스와의 구별성이 낮음
- preliminary trademark state: `TRADEMARK_HUMAN_VERIFICATION_REQUIRED`
- domain state: `momannae.com`은 RDAP 404·DNS 미해결·public archive no-capture 관찰만 있음; `DOMAIN_APPEARS_AVAILABLE_UNCONFIRMED`
- search-confusion state: `SEARCH_CONFUSION_MEDIUM`
- trust risk: 의료 권위는 낮지만 일반적 “안내”가 공적 권위처럼 보이지 않도록 operator·비의료 고지를 명확히 해야 함
- domain architecture fit: D1이 운영상 가장 단순하지만 기존 B2B 도메인 주제 불연속을 별도 관리해야 함
- 다음 사람 확인: KIPRIS 일반명사·유사표장, Naver exact query, 공공기관 오인 reader test

## 4. 곁건강 — Most Extensible Option

- 발음/로마자: 곁-건강 / `gyeotgeongang`
- 의미: 일상과 가족 곁에 두는 건강 정보
- tagline 후보: “가까이에서 읽는 쉬운 건강 정보”
- brand story: 질환별 설명, 가족용 질문, 기록 도구, 시각 교육을 한 브랜드 아래로 확장
- 강점: 건강 관련성이 직관적이고 20개 질환 이후의 편집 확장성이 큼
- 약점: 돌봄·웰니스 서비스로 오인될 가능성과 “건강” 일반명사 위험
- preliminary trademark state: `TRADEMARK_HUMAN_VERIFICATION_REQUIRED`
- domain state: `gyeotgeongang.com`은 RDAP 404·DNS 미해결 관찰만 있음; `DOMAIN_APPEARS_AVAILABLE_UNCONFIRMED`
- search-confusion state: `SEARCH_RESEARCH_INCOMPLETE`
- trust risk: 비의료 정보 제공자라는 경계를 header, about, corrections policy에서 반복해야 함
- domain architecture fit: D2/D3에서 topical separation이 명확하지만 신규 운영·검증 부담이 증가
- 다음 사람 확인: 건강·돌봄 유사 상표와 의료 제공자 오인 조사

## 5. 살핌길 — Backup Option

- 발음/로마자: 살핌-길 / `salpimgil`
- 의미: 정보를 차분히 살피고 다음 도움을 찾는 길
- tagline 후보: “알아두고 차분히 준비하는 건강 안내”
- brand story: 진단이나 치료 지시가 아닌, 이해·기록·질문의 다음 단계를 돕는 편집 길잡이
- 강점: 차분하고 성인·가족 독자에게 무난하며 공포 조장이 없음
- 약점: 건강 관련성이 낮고 생활서비스·교육 브랜드 일반어와 혼동될 수 있음
- preliminary trademark state: `TRADEMARK_HUMAN_VERIFICATION_REQUIRED`
- domain state: `salpimgil.com`은 RDAP 404·DNS 미해결 관찰만 있음; `DOMAIN_APPEARS_AVAILABLE_UNCONFIRMED`
- search-confusion state: `SEARCH_CONFUSION_MEDIUM`
- trust risk: 낮음, 단 tagline과 operator 고지가 있어야 건강교육 목적이 명확함
- domain architecture fit: D1에서 독자-facing brand layer로 쓰기 쉽지만 D2/D3와의 비용 비교 필요
- 다음 사람 확인: KIPRIS 관념 유사, Naver exact/spacing search, read-aloud spelling test
