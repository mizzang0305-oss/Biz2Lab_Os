# 곁살핌 초기 상표 분류 지도

상태: `HUMAN_IP_PROFESSIONAL_REVIEW_REQUIRED`
기준일: 2026-08-24 KST

대상 서비스는 현재 “비의료 건강정보 편집, 온라인 기사·설명·질문 준비 자료”이며 진단·치료·의료서비스가 아니다. 아래는 출원 범위를 정하는 법률 의견이 아니라, 사람이 KIPRIS 검색 범위와 전문가 상담을 준비하기 위한 현재 Nice 분류 참고표다.

| Nice class | 공식 분류·근거 | 현 계획과의 관계 | 초기 우선도 | 판단 한계 |
|---|---|---|---|---|
| 41 | 교육, 훈련, 출판을 포함한다. WIPO 2026 Class 41은 `publication of books`, `providing online electronic publications, not downloadable`를 열거한다. | 기사·비다운로드 온라인 정보·교육형 편집 콘텐츠와 가장 가까운 출발점 | `PRIMARY_REVIEW` | 실제 지정서비스 문구와 한국 유사군은 전문가가 확정 |
| 9 | WIPO 2026 Class 9은 `electronic publications, downloadable`를 열거한다. | 다운로드 가능한 PDF, 전자책, 오프라인 파일을 실제 제공할 때만 검토 | `OPTIONAL_IF_OFFERED` | 단순 웹페이지/비다운로드 콘텐츠만으로 자동 선택하지 않음 |
| 16 | 종이·인쇄물·교육용 교재 등을 다루는 분류다. WIPO는 인쇄 도서는 16, 다운로드 전자출판물은 9, 비다운로드 온라인 출판물은 41로 구분한다. | 인쇄 안내서·워크시트·책자를 실제 배포·판매할 때만 검토 | `OPTIONAL_IF_OFFERED` | 장래 가능성만으로 넓히지 않음 |
| 42 | 소프트웨어 설계·개발, SaaS/PaaS를 포함한다. | 독립적인 인터랙티브 소프트웨어/SaaS를 실제 출시할 때만 검토 | `FUTURE_OPTIONAL_IF_PRODUCT_EXISTS` | 정보성 웹사이트 자체를 42로 단정하지 않음 |

## Exclusions and Gate

- Class 44 의료서비스는 현재의 비의료 건강정보 편집 범위를 근거로 자동 추가하지 않는다.
- 의료전문가 검수 확보 진행 상태나 향후 의료 콘텐츠 가능성은 분류를 미리 확정하는 근거가 아니다.
- 실제 상품·서비스, 유사군, 출원 시점, 선행권리와의 중첩은 `HUMAN_IP_PROFESSIONAL_REVIEW_REQUIRED`다.
