# Human Verification Checklist

## KIPRIS

- [ ] final five의 한글 정확명 검색
- [ ] 띄어쓰기·붙여쓰기·로마자·발음 유사 검색
- [ ] 상표명칭, 권리자, 상태, 출원/등록번호, 지정상품·서비스, 유사군을 저장
- [ ] 출판·교육·온라인 정보·소프트웨어 관련 실제 사업 범위로 분류 입력도우미 확인
- [ ] 활성 또는 출원 중인 유사표장이 있으면 변리사 검토 요청

## Domain

- [ ] 최종 1~2개만 `.com`, `.kr`, `.co.kr`을 등록원에서 수동 조회
- [ ] 등록·예약·장바구니·구매는 Owner 별도 승인 전 금지
- [ ] 과거 사용, spam, malware, adult, gambling, counterfeit-medical 흔적 확인

## Search and trust

- [ ] Naver, Google, Bing, YouTube, 앱스토어에서 exact/spacing/romanized query 확인
- [ ] 병원·의료기관·정부·보험·약품·운세 서비스와의 혼동을 기록
- [ ] 비의료 독자 5명 이상에게 read-aloud protocol 실행
- [ ] 실제 응답을 기록하고 합성하거나 보정하지 않음
