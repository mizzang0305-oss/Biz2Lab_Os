# Brand Reader Test Protocol

상태: `HUMAN_BRAND_READER_TEST_PENDING`

## 대상

비의료 성인 5명 이상. 가능하면 보호자 경험이 있는 사람과 일반 독자를 섞되, 건강 상태·진단·의료기록은 수집하지 않는다.

## 진행

각 참가자에게 finalist 이름과 tagline을 한 번만 읽어 주고 다음을 묻는다.

1. 이 이름을 처음 들으면 어떻게 적을 것 같은가?
2. 건강 사이트라는 느낌이 나는가?
3. 병원이나 의료기관으로 오해할 가능성이 있는가?
4. 아이와 부모가 함께 봐도 자연스러운가?
5. 전화로 한 번 듣고 기억할 수 있는가?
6. 가족에게 링크를 보낼 때 신뢰가 가는가?

## 기록 규칙

- verbatim response, 추정 철자, 혼동 유형, 날짜만 최소 기록한다.
- 참가자 실명·연락처·건강정보는 기록하지 않는다.
- 응답을 만들어 내거나 긍정 응답만 선택하지 않는다.
