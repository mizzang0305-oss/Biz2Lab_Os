# Topic Cluster Plan

## Core linking rule

각 flagship은 최대 3개의 질환 관련 링크, 2개의 증상·예방 링크, 1개의 glossary 링크를 기본으로 한다. 관련성이 없는 링크를 숫자 채우기 위해 붙이지 않는다.
