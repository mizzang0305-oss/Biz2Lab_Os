# SYNTHETIC TEST — NOT REAL HUMAN FEEDBACK

## 목적

이 폴더는 오누림 Preview의 읽기 경험을 점검하기 위해 수행한 `SYNTHETIC_READER_SIMULATION` 기록입니다. 결과는 실제 사람의 사용성 조사, 환자 인터뷰, 의료인 검수 또는 임상 검토가 아닙니다.

## 범위와 한계

- 대상: 고혈압, 제2형 당뇨병 Preview 페이지의 실제 렌더링 화면
- 방식: 서로 다른 독자 관점 5개가 각 페이지를 독립적으로 평가한 10개 합성 평가
- 금지: 실제 사람으로 표현, 의료적 정확성 승인, 환자 경험 또는 동의가 있었다고 표현
- 실제 사람 테스트: `NOT_PERFORMED`
- 의료인 검수: `NOT_MEDICALLY_REVIEWED`

Round 1의 반복 발견은 최소 코드·문구 수정으로만 처리하며, Round 2에서 같은 독립 평가 기준으로 다시 확인합니다.
