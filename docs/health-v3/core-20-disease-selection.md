# Core 20 Disease Selection

- 확정일: 2026-08-21
- 목적: 초기 flagship portfolio를 정확히 20개로 제한
- 선정 방식: 국내 질환 부담, 응급·예방 가치, 가족 실용성, 설명 가능성, 신체계통 균형, 공식 출처 가용성
- 제외 기준: 출처가 약한 주제, 지나치게 세부적인 키워드 분할, 자가진단·자가치료 오해가 큰 주제

검색량 수치는 확보하지 않았으며 임의의 volume을 만들지 않았다. 현재 선택은 검색량 순위가 아니라 공식 통계와 환자교육 효용을 함께 본 editorial portfolio decision이다.

## Deferred candidates

빈혈, 신장결석, 통풍, 수면무호흡증, 변비, 위궤양, B형간염, 대상포진은 유용하지만 초기 20개에 억지로 넣지 않는다. Search Console의 실제 query, 독자 피드백, 출처 검토 능력, 사람 검토 여력을 확인한 뒤 후속 후보로 평가한다.

## Publication gate

20개 선정은 20개 동시 발행 승인이 아니다. 한 batch는 최대 2~4개이며 다음이 없는 글은 공개하지 않는다.

- page-specific provenance map
- 응급·진료 기준 source
- 사실 확인자와 확인일
- source-checked 표시의 정직한 문구
- 금지된 자가진단·용량 조언 없음
- plagiarism·similarity·readability 검토
