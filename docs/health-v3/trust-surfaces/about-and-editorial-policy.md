## Editorial Policy

# 편집 원칙

{{PUBLIC_HEALTH_BRAND_NAME}}는 다음 원칙으로 건강 콘텐츠를 준비합니다.

1. 질병관리청, 보건복지부와 국내 공공기관 자료를 우선 확인하고, 필요한 경우 국제 공공·비영리 보건기관 자료를 보조 근거로 사용합니다.
2. 출처 링크가 있다는 사실과 사람이 실제 문장을 원문에 대조했다는 사실을 구분합니다. 사람의 출처 확인이 끝나지 않은 글은 공개 준비 완료로 표시하지 않습니다.
3. 출처 확인은 면허 의료 검토와 다릅니다. 고혈압·제2형 당뇨병의 고위험 claim과 뇌졸중·심근경색 페이지 전체는 별도의 면허 의료 검토를 통과해야 공개 준비 후보가 됩니다.
4. 저자는 비의료 건강정보 편집자로 표시하며, 확인되지 않은 의료 자격·임상 경험·소속·추천을 주장하지 않습니다.
5. AI는 자료 정리, 구조 설계, 초안 작성, 시각 아이디어 구상을 도울 수 있지만 저자, 출처 확인자 또는 의료 검토자로 표시하지 않습니다.
6. 광고·제휴·수익 관계가 생기더라도 편집 판단과 구분하고 관련 페이지에서 공개합니다.
7. 사실 오류나 오해를 부르는 표현이 확인되면 영향도를 평가하고, 필요한 경우 출처 확인과 의료 재검토를 거쳐 수정합니다.

각 글에는 작성자, 출처, 확인 상태, 의료 검토 상태와 마지막 검토일을 실제 기록과 일치하도록 표시합니다. 완료되지 않은 절차를 badge나 모호한 `전문가 검토` 표현으로 대신하지 않습니다.
