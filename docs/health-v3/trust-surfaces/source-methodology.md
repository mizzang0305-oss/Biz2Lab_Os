# Source Methodology 공개 문구 초안

# 출처 선정과 확인 방법

{{PUBLIC_HEALTH_BRAND_NAME}}는 건강 정보를 작성할 때 국내 공공기관의 공식 자료를 우선 사용합니다. 질병관리청, 보건복지부와 관련 국가기관 자료를 먼저 확인하고, 필요한 경우 WHO, NIH/NLM, NHS 등 국제 공공·비영리 보건기관 자료와 공식 전문 지침을 보조 근거로 검토합니다.

상업 사이트, 언론 기사, 개인 블로그, 커뮤니티와 소셜 미디어는 핵심 의료 주장의 단독 근거로 사용하지 않습니다. 제품·서비스 판매와 직접 이해관계가 있는 자료는 이해상충을 검토하고 근거의 한계를 표시합니다.

## 확인 절차

1. 글의 정의, 증상, 응급 행동, 검사, 치료 범주, 약물 경계와 생활 관리 문장을 claim 단위로 분리합니다.
2. 각 claim에 원문 URL, 문서명, 기관, 확인일과 사용 범위를 연결합니다.
3. 실제 사람이 원문과 문장을 대조한 뒤에만 `SOURCE_CHECKED`로 기록합니다.
4. 출처의 날짜를 확인할 수 없거나 중요한 출처가 충돌하면 해당 claim과 글의 공개를 중단합니다.
5. 응급·진단·치료·약물 문장은 source check와 별도로 면허 의료 검토를 받습니다.
6. 핵심 출처나 의료 의미가 바뀌면 변경 이력을 남기고 필요한 재검토를 진행합니다.

공식 URL이 등록되어 있다는 사실, AI가 문장을 검토했다는 사실 또는 source checker가 문장을 대조했다는 사실은 면허 의료 검토와 같지 않습니다. 글마다 출처 확인 상태와 의료 검토 상태를 별도로 표시합니다.

오류가 의심되는 경우 정정 채널로 page URL, 정정 category와 설명을 보내 주시면 실제 사람이 검토합니다. 이 채널은 의료상담을 제공하지 않습니다.
