# 제2형 당뇨병 이미지 프롬프트 패키지

상태: `PROMPT_ONLY_NOT_GENERATED`

공통 제약: 한국어 건강 교육용 원본 벡터 일러스트, 따뜻하고 비낙인적, 다양한 체형 표현, 로고·제품·긴 이미지 텍스트 없음. 체중이나 음식 하나를 질환의 단일 원인으로 묘사하지 않는다.

## Hero

일상에서 혈당 기록을 살펴보고 의료진과 상담할 질문을 준비하는 성인의 모습, 배경에는 췌장과 혈액 속 포도당을 단순화한 상징을 배치한 16:9 일러스트. 질환을 개인의 의지 부족으로 표현하지 말 것.

Alt 초안: `혈당 기록을 살펴보고 진료 질문을 준비하는 사람과 혈당 개념 그림`

## Explainer

음식에서 얻은 포도당, 혈액, 인슐린 신호, 세포 이용의 관계를 네 단계로 단순화한 4:3 흐름도. 인슐린 저항성과 혈당 상승 개념을 설명하되 정확한 진단 수치나 자가 판정 표시 없음.

Alt 초안: `포도당이 혈액으로 들어오고 인슐린 도움으로 세포에서 이용되는 흐름`

## Warning signs

식은땀과 떨림·혼란 같은 저혈당 의심 신호, 심한 갈증·구토·의식 변화 등 긴급 평가가 필요한 신호를 두 구역으로 나눈 카드. 모든 당뇨 환자에게 같은 증상이 생긴다는 인상을 피하고, 구체 행동은 검수된 HTML에서 제공.

Alt 초안: `저혈당 의심 신호와 심한 고혈당 관련 위험 신호를 나눈 아이콘 카드`

## Management

정기 검사, 균형 잡힌 식사, 안전한 활동, 발 관찰, 처방약 상담을 다섯 장면으로 보여 주는 4:3 일러스트. 음식에 금지 도장을 찍거나 체형 전후 비교를 사용하지 않음.

Alt 초안: `검사, 식사, 활동, 발 관리, 약물 상담으로 구성된 당뇨병 관리 장면`

## 사람 검토 포인트

- 췌장·인슐린 흐름이 지나치게 단순화되어 잘못 이해되지 않는지
- 저혈당과 고혈당 위험 신호 구분
- 특정 식품·체형에 대한 낙인 여부
- 발 관리 장면이 상처 사진 없이 교육 목적을 달성하는지
