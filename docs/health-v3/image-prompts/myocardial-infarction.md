# 심근경색 이미지 프롬프트 패키지

상태: `PROMPT_ONLY_NOT_GENERATED`
안전 등급: `EMERGENCY_CONTENT_MEDICAL_REVIEW_REQUIRED`

공통 제약: 원본 벡터 건강 교육 스타일, 비공포·비선정적, 실제 환자·수술·심전도 모사 없음. 온라인 정보로 응급 요청을 늦추지 않게 즉시 도움 요청을 가장 분명하게 표현.

## Hero

심장과 관상동맥을 단순 선화로 보여 주고, 흉부 불편감을 느낀 사람이 주변에 알리고 전화로 도움을 요청하는 16:9 장면. 고통을 과장하지 않으며 다양한 사람에게 생길 수 있음을 존중감 있게 표현.

Alt 초안: `심장 혈관 그림 옆에서 흉부 불편감을 느끼고 전화로 도움을 요청하는 모습`

## Explainer

관상동맥 안의 혈류가 막히면서 심장 근육에 산소 공급이 줄어드는 과정을 세 단계로 표현한 4:3 도식. 해부학은 단순화하되 혈관과 심장 근육의 관계가 틀리지 않게 함.

Alt 초안: `관상동맥 혈류가 막혀 심장 근육의 산소 공급이 줄어드는 과정`

## Warning signs

가슴의 압박·통증, 팔·턱·등으로 번지는 불편감, 호흡 곤란, 식은땀·메스꺼움, 즉시 119 도움 요청을 카드로 표현. 모든 사람이 같은 증상을 겪는다고 단정하지 않으며 직접 운전 장면은 넣지 않음.

Alt 초안: `흉부 압박, 퍼지는 불편감, 호흡 곤란, 식은땀과 즉시 119 요청을 나타내는 카드`

## Management

응급 치료 후 진료 추적, 처방약 상담, 심장 재활, 금연과 위험 요인 관리를 보여 주는 일러스트. 응급 전 단계와 명확히 분리하고 특정 약물·시술의 결과를 보장하지 않음.

Alt 초안: `진료 추적, 처방 상담, 심장 재활, 금연으로 구성된 회복과 관리 장면`

## 사람 검토 포인트

- 관상동맥 위치와 혈류 방향
- 비전형 증상 설명이 공식 출처와 일치하는지
- 소화불량 등과 스스로 구분하라고 유도하지 않는지
- 즉시 119 요청과 직접 운전 금지 취지가 명확한지
