# 2026-10-03 신규 생활 건강 가이드 편집 근거

일반 교육 신규5편. 기존34편과 원본 claim/source/tool 증거 보존. 의료인 검수 미완료이며 실제 증상·접종내역·검사 입력/조회 없음. 위기 정신건강 비공개 후보는 이번 범위에 포함하지 않음.

## /health/guides/health-claim-before-forwarding

독자 질문: 건강 글을 공유해도 되는 근거인가?

마칠 일: 주장 하나→원문/대상/날짜/미확인 메모

구성: 가상 제목을 검증 질문으로 바꾸는 실습

근거: ODS_EVALUATE, NLM_EVALUATE

확인 범위: 작성자/운영주체/원문/후원/최신성 및 연구 대상 확인; 후기≠효과근거

중복 대조: 기존 trust 정책은 사이트의 편집 규정. 신규 글은 독자가 전달받은 한 주장을 확인하는 절차. 기존 검사표/질환/어제5편과 과제 구분.

## /health/guides/soap-or-sanitizer-different-jobs

독자 질문: 손소독제가 흙·기름 제거를 대신하나?

마칠 일: 손 상태→물비누 가용성→씻기/표시대로 소독→건조

구성: 상황 비교표+놓치는 부위 점검

근거: KDCA_HANDS, CDC_SANITIZER

확인 범위: 30초이상은 KDCA 요약문; 해당 문서 일반실천15~30초 표기도 존재. 요약 권고30초이상을 명시하며 출처간 시간을 혼합하지 않음.60%이상 CDC/KDCA; 제품 표시·오염·건조·아동감독

중복 대조: 기존 감염 질환 설명 또는 위험신호 글의 반복 아님; 일상 손위생 선택이 신규 과제.

## /health/guides/hearing-sound-and-words

독자 질문: 들리는 소리와 알아듣는 말은 같은 검사인가?

마칠 일: 즉시진료 신호 우선→검사질문→실제 대화환경 전달

구성: 앞선 경고+용어질문표+가상 표현 바꾸기

근거: NIDCD_SUDDEN, NLM_HEARING, NIDCD_AGE

확인 범위: 갑작스러운청력저하 즉시진료; 순음/어음 검사 목적; 배경소음/얼굴보기/비고함. 진단수치·OTC제도·치료명령 제외

중복 대조: 기존 진료 질문지는 공통 준비; 신규청력검사 및 소음 속 말이해 질문을 다룸.

## /health/guides/vaccination-record-not-found

독자 질문: 전산 미조회가 미접종의 증명인가?

마칠 일: 조회/원본/기억 구분→접종기관 문의→미확인 전달

구성: 서류 분류와 문의 경로

근거: KDCA_RECORD, KDCA_REGISTER

확인 범위: 공식 전산등록된 기록만 조회; 누락 등록문의/폐업관할보건소; 인증기능 실조회/임의재접종/미국일정 전용 없음

중복 대조: 기존 부모 건강자료 정리는 여러 기록 위치를 찾음; 신규는 접종 전산 미조회의 해석과 다음 문의처.
