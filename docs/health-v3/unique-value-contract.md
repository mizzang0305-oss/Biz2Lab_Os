# 4개 파일럿 고유 가치 계약

상태: `PILOT_EDITORIAL_CONTRACT`

질환 정의·증상·원인·치료 요약만으로는 파일럿을 완료한 것으로 보지 않는다. 각 페이지는 독자가 다음 행동을 준비할 수 있는 고유 편집 자산을 최소 4개 제공해야 한다.

## 고혈압

| Contract field | Value |
|---|---|
| Unique reader problem | 한 번의 혈압 수치에 놀라거나 측정 자세·기록 방법을 몰라 진료에 유용한 정보를 준비하지 못함 |
| Unique action | 동일한 조건으로 측정하고 7일 기록을 진료 질문과 연결 |
| Unique downloadable assets | 7일 혈압 기록지, 진료 질문표, 응급 신호 카드, 올바른 측정 체크리스트 |
| Unique visual lesson | 측정 자세와 커프 위치가 기록 신뢰성에 영향을 준다는 흐름 |
| Reason to revisit | 새 측정 기록을 추가하고 진료 전에 질문을 갱신 |
| Reason to share | 가족이 측정 환경과 응급 신호를 함께 확인 |
| Competitor overlap | 일반 고혈압 설명·생활관리와 일부 겹침 |
| Missing from generic summaries | 측정→기록→진료 질문→응급 행동이 한 도구 흐름으로 연결되는 경험 |

## 제2형 당뇨병

| Contract field | Value |
|---|---|
| Unique reader problem | 검사 이름과 일상 기록을 연결하지 못하고 수치에 따라 약을 스스로 바꿀 위험 |
| Unique action | 검사 용어를 구분해 질문을 만들고 음식·활동·측정 관찰을 약물 변경 없이 기록 |
| Unique downloadable assets | 혈당 용어표, 진료 질문표, 일상 관찰 기록지, 가족 지원 체크리스트 |
| Unique visual lesson | 포도당·인슐린·세포 이용 관계와 각 검사가 답하는 질문의 차이 |
| Reason to revisit | 진료 전 관찰 기록과 질문 업데이트 |
| Reason to share | 가족이 비난 대신 안전한 지원 행동을 합의 |
| Competitor overlap | 당뇨 정의·증상·생활관리와 일부 겹침 |
| Missing from generic summaries | 자가 약물 조절을 막으면서 관찰 자료를 진료 대화로 전환하는 도구 |

## 뇌졸중

| Contract field | Value |
|---|---|
| Unique reader problem | 증상이 잠깐 좋아지거나 확신이 없어 신고를 늦추고 가족이 필요한 정보를 준비하지 못함 |
| Unique action | 갑작스러운 얼굴·팔·말 변화를 인지하고 즉시 119, 시작 시각과 병력 준비 |
| Unique downloadable assets | 한국어 응급 신호 기억 카드, 가족 행동 카드, 약물·병력 준비표, 퇴원 후 질문표 |
| Unique visual lesson | 증상 판별 퀴즈가 아니라 발견→119→시각 기록의 우선순위 |
| Reason to revisit | 가족 응급 준비와 퇴원 후 질문 업데이트 |
| Reason to share | 가족 모두가 같은 즉시 행동을 기억 |
| Competitor overlap | FAST형 증상 설명과 일부 겹침 |
| Missing from generic summaries | 응급 신고 전후 가족의 정보 준비를 안전한 순서로 분리한 실용 자산 |

## 심근경색

| Contract field | Value |
|---|---|
| Unique reader problem | 소화불량·근육통인지 스스로 구분하려다 119 요청을 늦추고 회복기 질문을 놓침 |
| Unique action | 심각한 경고 신호가 있으면 자가 구분을 중단하고 119, 응급·회복 정보를 분리해 준비 |
| Unique downloadable assets | 응급 경고 카드, 응급 정보표, 시술 후 질문표, 회복 관찰 체크리스트 |
| Unique visual lesson | 증상 다양성→자가 판별 금지→119의 흐름과 회복기 질문의 별도 흐름 |
| Reason to revisit | 응급 정보와 회복 관찰 내용을 가족과 갱신 |
| Reason to share | 직접 운전·자가 치료 대신 도움 요청 행동을 가족이 합의 |
| Competitor overlap | 흉통·호흡곤란·식은땀 설명과 일부 겹침 |
| Missing from generic summaries | 응급 인지와 시술·퇴원 후 질문 준비를 한 페이지 제품으로 연결 |

## 완료 게이트

- [ ] 각 자산이 교육용이며 진단·처방 도구가 아님을 명시
- [ ] 자산의 의료 claim이 registry와 연결
- [ ] 응급 자산은 면허 검토 완료 전 공개 차단
- [ ] 인쇄·모바일 사용성 사람 테스트
- [ ] 경쟁 페이지 문구·레이아웃·도판을 복제하지 않음
- [ ] 실제 독자 3명의 응답 기록
