# 출처 선정과 확인 방법

{{PUBLIC_HEALTH_BRAND_NAME}}는 질병관리청, 보건복지부와 국내 공공기관의 공식 자료를 우선 사용합니다. 필요한 경우 WHO, NIH/NLM, NHS 등 국제 공공·비영리 보건기관 자료와 공식 전문 지침을 보조 근거로 검토합니다.

## 확인 절차

1. 정의, 증상, 응급 행동, 검사, 치료 범주, 약물 경계와 생활 관리 문장을 claim 단위로 분리합니다.
2. 각 claim에 기관, 문서명, 원문 URL, 확인일과 사용 범위를 연결합니다.
3. 실제 사람이 원문과 문장을 대조한 뒤에만 `SOURCE_CHECKED`로 기록합니다.
4. 날짜를 확인할 수 없거나 중요한 출처가 충돌하면 claim과 글의 공개를 중단합니다.
5. 응급·진단·치료·약물 문장은 source check와 별도로 licensed medical review를 받습니다.
6. 핵심 출처나 의료 의미가 바뀌면 변경 이력을 남기고 필요한 재검토를 진행합니다.

공식 URL 등록, AI 검토 또는 source check는 licensed medical review와 같지 않습니다. 각 상태를 별도로 표시합니다.
