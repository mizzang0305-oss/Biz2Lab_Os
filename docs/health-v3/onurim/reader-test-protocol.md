# 오누림 두 파일럿 독자 테스트

대상은 비의료 한국어 성인 최소 5명이다. 실제 응답 전에는 점수·인용·통과 상태를 만들지 않는다. 개인 병력·검사값·복용 약 등 의료정보는 묻거나 저장하지 않는다.

## 진행

1. 보호된 Preview에서 고혈압과 제2형 당뇨병 페이지를 각각 읽는다.
2. 기록 도구 중 최소 하나를 열어 모바일과 인쇄 관점에서 확인한다.
3. 아래 질문과 유용성·신뢰 점수를 익명 reader ID로 기록한다.
4. 위험한 오해 또는 의료상담처럼 받아들인 표현은 즉시 `BLOCKED_MEDICAL_SAFETY_FINDING` 후보로 분류한다.

## 질문

1. 이 글이 무엇을 설명하는지 이해됐습니까?
2. 가장 도움이 된 부분은?
3. 이해하기 어려운 문장은?
4. 너무 AI처럼 느껴지는 부분은?
5. 너무 겁을 주는 부분은?
6. 병원에 가야 하는 시점이 이해됩니까?
7. 의료상담으로 오해할 표현이 있습니까?
8. 저장하거나 출력하고 싶은 도구가 있습니까?
9. 가족에게 공유할 의향이 있습니까?
10. 다시 방문할 이유가 있습니까?

## 통과 gate

- 실제 독자 5명 이상
- 심각한 의학적 오해 0건
- 가짜 의료 권위 인식 0건
- 평균 유용성 4.0/5 이상 권장
- 평균 신뢰 4.0/5 이상 권장
- 주요 혼란 문장 수정 완료
- 위험한 해석 미해결 0건

현재 상태: `HUMAN_READER_TEST_PENDING`.
