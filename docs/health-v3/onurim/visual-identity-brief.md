# 오누림 visual identity brief

## 방향

- soft modern health education
- 차분한 청록과 따뜻한 모래색, 충분한 흰 공간
- 둥글지만 유아적이지 않은 형태
- 이해가 겹겹이 선명해지는 층, 연결되는 점, 펼쳐지는 길을 보조 모티프로 사용
- 360px 화면에서 먼저 읽히는 큰 제목과 단순한 카드 구조

## 금지

- 적십자, 병원 십자, 정부 인장과 유사한 표식
- 알약, 청진기, ECG 선, 카두세우스
- 흰 가운을 통한 권위 암시
- 공포·출혈·실제 환자 기록 화면

## Preview 적용

wordmark는 텍스트 `오누림`만 사용한다. 상표 등록 또는 최종 logo 확정으로 표현하지 않는다. 모든 화면 하단에 `운영: Biz2Lab`을 표시한다.
