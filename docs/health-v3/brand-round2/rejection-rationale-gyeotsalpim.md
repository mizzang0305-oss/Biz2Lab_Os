# `곁살핌` / `살핌길` 제외 근거

상태: `GYEOTSALPIM_REJECT_NEW_BRAND_ROUND_REQUIRED`

`곁살핌`은 KIPRIS에서 `살핌 (SALPIM)`의 Class 41·44 출원 신호가 확인된 이전 조사와, 돌봄·복지·상담·건강 문맥으로 강하게 이어지는 공개 검색 신호 때문에 제외한다. 이것은 특정 표장이 법적으로 충돌한다고 단정하는 결론이 아니다.

Health V3는 건강 교육·디지털 편집 콘텐츠를 포함할 예정이므로, 방어 비용을 감수하며 약한 root를 유지할 이유가 없다는 사업 판단을 적용했다. `살핌길`도 같은 dominant root를 공유하므로 함께 영구 제외한다. Owner가 명시적으로 요청하기 전에는 이 두 이름을 IP 전문가에게 구조 요청하지 않는다.
