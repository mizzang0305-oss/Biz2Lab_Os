# Final-Three Visual Micro-Briefs

## 하도림

- wordmark: 여백이 넓은 rounded grotesk, 자간을 과도하게 좁히지 않는다.
- icon territory: 한 장의 종이에서 차분히 정돈되는 작은 점·선. 복잡한 신호등/알람은 피한다.
- tone: warm ink, muted blue-green, editorial calm.
- trust rationale: 의료 권위 표식이 아니라 읽기·정리의 태도를 보여준다.

## 아노림

- wordmark: 단정한 humanist sans, `ㅇ`의 부드러운 리듬을 활용한다.
- icon territory: 열린 괄호/문장 단락/작은 관찰점.
- tone: off-white와 deep navy, 과도한 tech-gradient 금지.
- trust rationale: 쉽게 읽히는 정보라는 정체성을 시각화한다.

## 오누림

- wordmark: 어른과 가족 모두 읽기 쉬운 넓은 x-height의 한글 서체.
- icon territory: 겹치지 않는 세 개의 부드러운 arc 또는 함께 보는 페이지.
- tone: muted amber를 보조색으로만 사용.
- trust rationale: 병원 대신 공동 이해의 공간이라는 신호를 준다.

공통 금지: red medical cross, caduceus, doctor coat, hospital silhouette, government seal, pill icon, stethoscope cliché. 이는 Production logo가 아닌 conceptual brief다.
