# Naming Strategy

## 목표

이름은 이해·신호·방향·질문·기록·가족·배움의 정서를 담되, 병원·진료·보험·정부·돌봄기관처럼 들리지 않는 독립적 편집 브랜드여야 한다. 한국어 2–4음절, 로마자 5–10 alphabetic characters, 하나의 자연스러운 표기를 우선한다.

## 제외 규칙

`살핌`, `살피`, `건강`, `몸`, `헬스`, `케어`, `메디`, `닥터`, `클리닉`, `병원`, `질병`, `질환`, `진단`, `처방`, `치료`, `약`, `국민`, `국가`, `공식`, `보건`, `의료`와 이를 살짝 바꾼 dominant root는 제외했다. tag line에 사실에 맞는 설명어로 쓰는 문제와 core brand root는 분리한다.

## 평가 방법

언어 단계는 기억성·발음·철자·온기·성인 신뢰·아동 이해·편집 적합성·확장성·구전성·시각성·도메인 적합성·식별성을 1–5로, genericness·의료/공공/돌봄/상담/제약 오인·동음 위험·로마자 모호성·오타·AI 느낌을 0–5로 기록했다. 평균점수만으로 통과시키지 않고 hard gate를 적용했다.

## 외부 사전조사

60개에는 exact quoted/plain 및 health/provider/app/company context를 progressive funnel로 적용했다. exact commercial use, 높은 root 포화, 또는 provider/public-service 오인은 즉시 중단·제외했다. KIPRIS는 25개를 `상표명칭(TN)` + `완전일치`로 조회했다. 이 검색은 유사상표 판단이나 class-safe 결론을 제공하지 않는다.

## Nice class 관찰 범위

2026년 적용 NICE 13판을 기준으로 41(교육·훈련·문화 활동), 9(디지털 소프트웨어/다운로드 가능 자료), 16(인쇄물), 42(소프트웨어·기술 서비스)를 우선 관찰하고 44(건강·위생 서비스)는 public-confusion watch로만 다룬다. 같은 class가 곧 충돌도, 다른 class가 안전도 아니다.
