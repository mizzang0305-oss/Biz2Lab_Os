# 1차 콘텐츠 웨이브 계획

상태: `SOURCE_BACKED_BRIEF_ONLY`
공개 상태: `NOT_READY_FOR_PUBLICATION`

## 1. 범위

첫 웨이브는 핵심 20개 중 다음 4개만 상세 초안 대상으로 삼는다.

| 순서 | 질환 | 선택 이유 | 공식 근거 | 발행 전 추가 게이트 |
|---|---|---|---|---|
| 1 | 고혈압 | 흔하고 무증상일 수 있어 측정·관리 교육 가치가 큼 | KDCA KR-003 | 진단 기준·측정법 최신성 검수 |
| 2 | 제2형 당뇨병 | 검사·합병증·생활 관리 의도가 분명함 | KDCA KR-004 | 저혈당·약물 표현 검수 |
| 3 | 뇌졸중 | 위험 신호와 빠른 119 행동의 공익 가치가 큼 | KDCA KR-017 | 응급 문구 별도 의료 검수 |
| 4 | 심근경색 | 흉통 등 위험 신호와 응급 행동 교육 가치가 큼 | KDCA KR-018 | 응급 문구 별도 의료 검수 |

정확한 검색량은 확보하지 않았으며, 검색량 수치를 선택 근거로 주장하지 않는다.

## 2. 제작 순서

### Batch 0 — 신뢰 기반

- 실제 운영 주체와 책임 편집자 확인
- 의료 검수 가능 여부와 표시 방식 결정
- 편집·의학 검토·정정·개인정보·광고 정책 초안 확정
- 출처 레지스트리와 이미지 provenance 저장 방식 확정

Batch 0이 승인되지 않으면 기사 초안은 로컬 `draft + noindex`를 유지한다.

### Batch 1 — 만성질환 교육 초안

- 고혈압
- 제2형 당뇨병

각 글은 정의·위험 요인·증상·검사·관리·진료 시점·FAQ·출처를 갖춘다. 특정 약물 용량이나 개인별 식단 처방을 제공하지 않는다.

### Batch 2 — 응급 인지 교육 초안

- 뇌졸중
- 심근경색

두 글은 일반 기사보다 엄격한 응급 행동 검토를 거친다. 독자가 온라인 자가 점검 때문에 119 신고를 지연하게 만드는 인터랙션은 만들지 않는다.

## 3. 기사별 고유 정보 가치

### 고혈압

- 증상이 없어도 측정이 필요한 이유
- 가정혈압 측정에서 흔히 틀리는 자세와 준비
- 한 번의 수치와 의료진의 진단이 다른 이유
- 기록을 진료에 가져가는 방법

### 제2형 당뇨병

- 혈당 검사 종류가 서로 다른 질문에 답한다는 점
- 무증상 검진과 증상이 있는 진료의 차이
- 저혈당 위험 신호와 약물 임의 변경 금지
- 합병증 검사가 필요한 이유

### 뇌졸중

- 얼굴·팔·말 변화가 생겼을 때 시간을 기록하고 즉시 119에 연락하는 행동
- 잠깐 좋아져도 평가가 필요한 이유
- 뇌경색과 뇌출혈을 독자가 증상만으로 구분할 수 없다는 경계

### 심근경색

- 전형적 흉통 외에도 나타날 수 있는 신호
- 직접 운전보다 응급 도움 요청을 우선하는 이유
- 소화불량과 스스로 구분하려다 지연하지 않도록 하는 경계

위 항목은 기사 방향이며, 실제 의료 문장은 원문 출처 재확인과 사람 검수 후 작성한다.

## 4. 내부 링크 계약

- 모든 글 → 질환 허브
- 고혈압·당뇨병 → 이상지질혈증·비만·지방간 예정 글
- 뇌졸중·심근경색 → 고혈압·당뇨병·이상지질혈증 위험 요인 글
- 응급 글끼리는 `증상이 겹쳐도 독자가 구분해 기다리지 말 것`이라는 안전 경계를 유지
- 관련성이 없는 글을 링크 수 확보 목적으로 연결하지 않음

## 5. 완료 정의

`HEALTH_V3_FIRST_WAVE_CONTENT_READY`는 다음을 모두 충족할 때만 사용할 수 있다.

- 4개 완성 초안과 각 문장별 핵심 출처 매핑
- 실제 저자 정보 확인
- 의학 검토 방식 확정 및 수행 사실 기록
- 16개 원본 시각 자산의 의미·저작권·접근성 검수
- 초안은 로컬/Preview에서 `noindex`
- lint, typecheck, content QA, 내부 링크, 구조화 데이터 검증 통과
- Owner의 명시적 사람 검토

현재는 위 조건을 충족하지 않으므로 이 상태를 사용하지 않는다.
